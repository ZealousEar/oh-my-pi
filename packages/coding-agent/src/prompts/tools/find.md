Describe behavior, get implementing files and line ranges. MUST use first for unknown locations; known strings/regex/symbols → `grep`, names → `glob`.
`query`: plain language, not regex; quoted phrases match whole. `grep_keywords`: likely verbatim terms, `[]` if unsure.
`path`: one directory or file, host path or internal URL (`omp://`, `omp://<file>.md`, `skill://<name>`, `local://…`); omitted = workspace root. Scope known subsystem; batch related questions. Searches live files, no index; no `:start-end` selector (judges whole files).
Hits strongest first: `path:start-end score snippet` (workspace-relative, or URL under URL scope); read returned ranges. Scores: absolute comparable 0–1 probability; below ~0.4 = weak evidence, so widen query or use `grep` before concluding absence.

Bounded mode (`paths` instead of `path`): when you know roughly *where* the answer lives but not the words. `paths` = the ONLY content read — files, globs (`src/tools/*.ts`, `local://*.md`), internal URLs (`artifact://`, `local://`, `agent://`, `skill://`); directories rejected, nothing else sent. `unit`: `line` scores single lines, `paragraph` blank-line blocks, `auto` (default) picks per file — lines for short prose, indentation-aware blocks for code, paragraphs for long prose. `limit`: passages returned (default 8). `context`: extra lines around each hit. Caps: {{maxFiles}} files, {{maxBytesPerFile}} bytes per file, {{maxPassages}} passages total; oversized/binary/unreadable inputs skipped with a stated reason, never half-read.
Bounded output: `coverage`, `skipped …`, then `answerPresent P — verdict`, then each hit `path:start-end  score` with passage rows `*N:` and context rows ` N:`; re-read with `read path:start-end`. `answerPresent` is an independent probability, NOT the ranking: ranking probabilities sum to 1, so the top passage is only "the closest one"; low `answerPresent` = the named files likely lack the answer — evidence about those files, never proof about the repository.
Scores come from a judgment model: verify a hit by reading it before acting on it.
